# Project agent entry point

Read [CLAUDE.md](CLAUDE.md), [README.md](README.md), and
[docs/engineering-policy.md](docs/engineering-policy.md) before project work.
The shared policy is included here so contributors do not need the owner's private vault.
Follow the latest user direction and report material conflicts. Project facts and commands
come from this repository; do not apply another project's stack or database conventions.

Do not create sub-agents or persistent specialist roles without the user's selection
of the exact tasks and allowed files. Continue with one coordinator by default.
